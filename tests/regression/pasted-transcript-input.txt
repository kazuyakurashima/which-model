### Fixed instruction

あなたは技術ドキュメントの独立監査者です。以下のリポジトリのドキュメント群について、
`[Official]` タグ付きの記述が本当に Anthropic の公式情報に裏付けられているかを、
端から端まで監査してください。作業は自分でスコープし、行動できる十分な情報があれば
質問を待たずに進めてください。監査に必要な範囲を超えるドキュメントの改善提案・
リファクタ・書き換えはしないでください（指摘の報告まで）。

手順の目安：
1. <sources_ledger> の各 source_id（S1〜S66 等）について、記載された出典 URL・文書を
   WebFetch / WebSearch で実際に取得し、内容が現存・一致するか確認する。
2. 各ドキュメントの `[Official]` 記述を、対応する source_id の実際の公式記述と突き合わせ、
   「一致 / 誇張・歪曲 / 出典に記載なし / 出典が非公式」に分類する。
3. `[Heuristic]` タグの記述は監査対象外とするが、`[Official]` を名乗るべきでない記述が
   `[Official]` になっていないかは確認する。
4. 出典 URL が取得不能・変更されている場合は、その旨と代替の公式ソース候補を記録する。
