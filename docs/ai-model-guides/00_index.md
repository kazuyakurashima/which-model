# AI Model Guides — Claude Code モデル別プロンプト最適化リファレンス

このディレクトリは、Claude Code でコーディングする際に **どの開発タスクを、どのモデル（Fable 5 / Opus 4.8 / Sonnet 5）に、どんな形式で依頼するか** を判断するための運用リファレンスです。

## 設計の前提（重要）

このリファレンスは 2 層で構成されています。混同を避けるため、各記述には必ずタグが付いています。

- **`[Official]`** … Anthropic 公式ドキュメントで確認できる事実。`source_id` で `01_sources_evidence.md` に紐づく。
- **`[Heuristic]`** … このプロジェクト固有の運用仮説・経験則。公式の裏付けはない。`Confidence` 付き。

**`[Official]` と `[Heuristic]` を絶対に混同しないこと。** 「公式がそう言っている」のか「自分たちがそう運用すると決めた」のかが曖昧になると、半年後にこのドキュメント全体の信頼性が崩れる。

## ファイル構成と読み込みルール

Claude Code に **毎回すべてを読ませない**。タスクに応じて必要なファイルだけを参照する。

| ファイル                       | 中身                                  | いつ読むか                         |
| ------------------------------ | ------------------------------------- | ---------------------------------- |
| `00_index.md`（本ファイル）    | 全体の使い方・読み込みルール          | 最初の一度だけ                     |
| `01_sources_evidence.md`       | 根拠台帳（source_id ↔ 公式主張）      | 記述の裏付けを追いたいとき／更新時 |
| `02_model_selection_matrix.md` | タスク × モデル × 指示テンプレ 判断表 | **モデルを選ぶたび（最頻出）**     |
| `03_fable5_prompting.md`       | Fable 5 専用プロンプティングガイド    | Fable 5 に投げる直前               |
| `04_opus48_prompting.md`       | Opus 4.8 専用プロンプティングガイド   | Opus 4.8 に投げる直前              |

CLAUDE.md への追記スニペットは `99_CLAUDE_md_snippet.md` にある。

## 30 秒で分かる要約

- **迷ったら Opus 4.8。** 複雑なエージェント型コーディング・エンタープライズ作業の既定の出発点。`[Official]` (S1)
- **最高能力が要るなら Fable 5。** 人間が数時間〜数週間かける、長時間・曖昧・端から端までの作業向け。速い対話には不向き。`[Official]` (S2, S3, S9)
- **速度と知性のバランスなら Sonnet 5。** 日々の反復実装の主力。コーディング・エージェント作業に特に強く、Opus 級に移らず高い能力が要る場面の選択肢。`[Official]` (S11)
- **effort パラメータの調整は、モデル切り替えよりも先に試すべきレバー。** `[Official]` (S6)
